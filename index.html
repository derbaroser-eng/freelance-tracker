Enterprise CRMs are overbuilt. They require setup, training, and a monthly subscription. Freelancers need something that works in 30 seconds.

Existing tools are either too simple or too complex.

What it does

A CLI tool with local SQLite storage. Track:

clients

Name, email, hourly rate.

projects

Client, name, status (active, completed, cancelled).

invoices

Amount, due date, status (unpaid, paid, overdue).

How it works

$ python tracker.py add-client --name "Acme Corp" --email "billing@acme.com" --rate 75
{"id": 1, "name": "Acme Corp", "email": "billing@acme.com", "rate": 75.0}

$ python tracker.py add-invoice --client "Acme Corp" --amount 1500 --due 2026-02-01
{"id": 1, "amount": 1500.0, "status": "unpaid", "due_date": "2026-02-01"}

$ python tracker.py mark-paid --invoice-id 1
{"id": 1, "status": "paid"}
